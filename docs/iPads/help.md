# Problemlösungen

## Was mache ich wenn die Anmeldung in den Apps nicht funktioniert?
Oft kann es helfen, die Apps zu deinstallieren und neu zu installieren. Sollte das Problem weiterhin bestehen, wenden Sie sich bitte mit einer detaillierten Fehlerbeschreibung an den [Helpdesk](../index.md#keine-antwort-gefunden).


## Was mache ich wenn das Gerät nicht mehr funktioniert?
Häufig hilft es, das Gerät neu zu starten. Sollte das Problem weiterhin bestehen, kann es helfen, das Gerät auf die Werkseinstellungen zurückzusetzen. Bitte beachten Sie, dass dabei alle Daten auf dem Gerät gelöscht werden.

# Anleitung Eltern Login in WebUntis

Auf unserer [WebUntis-Startseite](https://paedagogium-schwerin.webuntis.com) steht ab sofort die Selbstregistrierung für Erziehungsberechtigte zur Verfügung.

Sofern die E-Mail‑Adresse im System gefunden wird, kann ein Account angelegt werden. Die Schüleraccounts werden anschließend automatisch zugeordnet. **Damit die Anmeldung funktioniert, müssen Sie die gleiche E‑Mail‑Adresse verwenden, die im Schulvertrag hinterlegt wurde.**

![](ElternRegis.png)

1. Rufen Sie die [WebUntis-Startseite](https://paedagogium-schwerin.webuntis.com) auf.
2. Wählen Sie die Option zur "Registrierung" aus.
3. Geben Sie Ihre E‑Mail‑Adresse ein, die im Schulvertrag hinterlegt ist. Anschlißend wird Ihnen ein Bestätigungscode zugesendet.
4. Legen Sie ein Kennwort fest und schließen Sie die Registrierung ab. Anschließend können Sie sich mit Ihren Zugangsdaten anmelden.
5. Der Account kann auch für die „Untis Mobile" App verwendet werden. Eine Anleitung dafür finden Sie [hier](app-login.md).


Seitens der Schule können keine Eltern-Accounts angelegt werden, die Erstellung funktioniert ausschließlich über die Selbstregistrierung.
Bei Problemen oder Fragen wenden Sie sich bitte mit Ihrer privaten E‑Mail‑Adresse und dem Namen der Kinder an den [Helpdesk](../index.md#keine-antwort-gefunden).
